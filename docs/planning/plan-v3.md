# PCG-创客星球 v3 — 主动设计·创新KOC核心模块

## 用户明确要求的3个核心模块（必须实现）

### 模块一：人设DNA提取引擎 (BrandDNAExtractor.tsx)
- 左侧内容喂料区（粘贴3段文案）
- 全屏扫描动画（CSS扫描线）
- 右侧人设雷达图（5维：幽默/情绪/专业/亲和/攻击）
- 结果持久化到 localStorage('koc_dna_profile')

### 模块二：爆款沙盘模拟器 (ViralitySimulator.tsx)
- 挂载在创作工坊生成结果下方
- 终端风格控制台（打字机输出）
- A/B版横向对比（标题悬念vs原稿）
- 进度条：曝光量/互动率/爆款概率
- 结论高亮：AI优化建议

### 模块三：商业变现反向匹配器 (MonetizationRadar.tsx)
- 发布成功后弹窗
- 旋转雷达动画
- 1-3个虚拟商单卡片瀑布流
- 匹配度评分+匹配原因
- "⚡️ AI生成自荐信并投递"按钮

## AI工作流设计（自主思考·深度创新）

### 核心痛点 → 解决方案映射

| KOC痛点 | 传统工具怎么做 | 我们的创新方案 |
|---------|---------------|---------------|
| 内容定位模糊 | 手动填写标签 | DNA引擎自动提取人设 |
| 不知道发什么 | 随机推荐 | 选题智库终端情报+下钻热力 |
| 发了没人看 | 事后分析 | 爆款沙盘事前预测 |
| 不知道怎么变现 | 自己找品牌 | 变现雷达自动匹配商单 |
| 内容风格不稳定 | 靠感觉 | DNA强制上下文锁定风格 |
| 不会写标题 | 套用模板 | AI变异AB测试 |
| 不知道哪版更好 | 凭直觉 | 数据化对比+AI建议 |

### 新增自主设计功能

#### 4. 情绪曲线编辑器 (EmotionCurveEditor)
- 在时间轴上编辑视频/推文的情绪波动
- 可视化情绪峰值（悬念→高潮→反转）
- AI根据情绪曲线生成对应文案

#### 5. 竞品解构克隆器 (CompetitorDeconstructor)
- 粘贴竞品爆款链接
- AI解构：标题公式+封面构图+情绪节奏+互动钩子
- 一键克隆改编

#### 6. 发布时机预言家 (TimingOracle)
- 分析粉丝活跃时间
- 结合热点事件日历
- 推荐最佳发布时间点

#### 7. 评论回复AI训练场 (ReplyTrainingGround)
- 模拟粉丝评论
- AI生成高情商回复
- 人设一致性检查
