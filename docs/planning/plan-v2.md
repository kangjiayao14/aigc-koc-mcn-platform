# PCG-创客星球 — 第二轮迭代改进计划

## 核心改进目标
在千人大赛中脱颖而出的关键迭代，解决用户提出的所有痛点，同时自主提升AI工作流的真实性和说服力。

---

## 改进任务清单

### 1. 主页动态化 (Priority: Critical)
- 英雄区星球从静态图改为动态效果
- 方案：视频背景 + 粒子特效 + 3D旋转星球
- 生成新的动态星球视频背景
- 保持赛博朋克风格的同时更加绚丽

### 2. 经纪人一致性 (Priority: Critical)
- 统一经纪人名字：男-凌霄，女-雅琪
- 选择界面展示大图+详细风格描述
- 所有页面Agent保持一致（名字+图像）
- 经纪人在对话中图像更大更醒目

### 3. 新增"内容大厅"页面 (Priority: Critical)
- 类似小红书/抖音首页的双列瀑布流
- 展示虚拟内容账号的帖子（美食/科技/旅行/穿搭/职场等）
- 点击头像进入个人主页（可关注/私信）
- 推荐算法标签（关注/推荐/热门/附近）
- 炫酷卡片设计（赛博朋克风格小红书）

### 4. 页面结构调整 (Priority: High)
- 导航栏调整：内容大厅 | 创作工坊 | 选题智库 | 社交星球 | 大V研讨室(蒸馏) | 个人主页 | 任务中心
- 商城移到个人主页内或底部
- 新增好友列表+聊天页面
- 个人主页和任务作为独立导航项

### 5. 创作工坊全面美化 (Priority: Critical)
- 改名：内容实验室→创作工坊
- 找真实小红书/朋友圈/抖音/领英背景界面
- 生成内容直接呈现在真实平台背景上
- 一键发布到PCG创客星球平台
- 经纪人图像放大（占屏幕30%+）
- 功能分区更明显（大区块+大图标）
- 图像美妆室预置演示图（不用上传）
- 预设按钮链路（评委无需打字即可体验完整流程）
- 平台风格模板：朋友圈/微信说说/小红书/领英/抖音

### 6. 选题智库全面改进 (Priority: Critical)
- 改名：选题雷达→选题智库
- 竞品解构放最前面，然后热力图+趋势分析
- 不分按钮，一页展示所有分析
- 热力图美化：大小表达热度，主题间连线（共现率>阈值才连线）
- 相近主题靠得近，动态微晃动
- 可下钻：广义主题→细分主题（如求职→秋招/春招/跳槽/简历）
- 新增内容效果分析：点击率、收藏率/阅读率等
- 热门搜索预设demo（借鉴用户提供的终端式设计）
- 新增平台战局柱状图（各平台内容量对比）
- 新增格式六维雷达图（长视频/短视频/图文/互动/直播/音频）
- 搜索后终端式分析动画

### 7. 腾讯视频联动 (Priority: High)
- 明确标注"腾讯视频联动放映厅"
- 会员专属影片标识
- 美化观影界面

### 8. 新手指引系统 (Priority: High)
- 完成入驻后进入个人主页
- 箭头+文字指引依次指向：
  1. 功能区（金币/等级）
  2. 等级进度
  3. 导航栏各功能说明
- 可跳过指引

### 9. AI工作流真实打通 (Priority: Critical)
- 每个AI功能都要有真实可运行的模拟流程
- 预设demo数据让评委一键体验
- 清晰的链路：选题→内容生成→发布→数据分析
- 在代码中标注每个API接入点

### 10. 专家工坊改名 (Priority: Medium)
- 专家工坊→大V研讨室（蒸馏）
- 强调"蒸馏"概念

---

## 执行顺序

### Phase 1: 全局调整（并行）
- 导航栏结构调整
- 页面改名
- 经纪人名字统一

### Phase 2: 核心页面改进（并行）
- 主页动态化
- 内容大厅新增
- 创作工坊美化
- 选题智库改进

### Phase 3: 社交+其他改进（并行）
- 社交星球美化+腾讯视频联动
- 大V研讨室改名
- 新手指引系统

### Phase 4: 整合+部署
- 合并所有分支
- 构建测试
- 部署上线
