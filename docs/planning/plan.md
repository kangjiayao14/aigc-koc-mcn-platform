# PCG-创客星球 — 赛博朋克风KOC社媒AI Agent平台

## 项目概述
打造一个极具未来感、赛博朋克风格的网页版AI Agent产品，面向KOC（关键意见消费者），帮助其低成本、高效率实现账号成长。产品需要在一千多人的比赛中脱颖而出，进入前10%。

## 设计方向
- **风格**: 赛博朋克 + 未来科技感，低饱和霓虹色调，非AI味儿的商业化艺术设计
- **交互**: 鼠标追踪特效、页面转场动画、3D动态元素、粒子效果
- **音乐**: 背景音乐支持
- **参考**: jiejoe.com 的设计感

## 核心功能模块
1. **开场页面** - 痛点展示 + 开始旅程按钮
2. **时空漩涡过渡** - 选择MCN经纪人（男/女）
3. **MCN引导对话** - 聊天式信息收集（年龄、性别、爱好、MBTI、星座、领域等）
4. **任务系统** - 主线/每日/彩蛋任务 + 经验金币 + 商店
5. **一键生成推文** - AI对话式生成 + 图像美化化妆间 + 风格切换
6. **选题分析** - 可视化分析 + 爆款搜索 + AI讲解
7. **每日爆款推荐** - 真实链接推荐
8. **社交板块** - 加好友、线上电影院（8人观影+语音社交）、线上剧本杀（AI DM）、小游戏
9. **内容研讨地** - AI人格蒸馏讨论群（QQ群形式）
10. **悬浮Agent** - 右下角小图标聊天入口
11. **个人主页** - 小红书/抖音风格展示

## AI功能链路（需标注API配置位置）
- LLM对话 Agent（经纪人对话、内容生成）
- 图片生成模型（配图生成）
- 图片解析/美化模型（P图、换衣、换发型）
- 外部搜索（爆款内容搜索）
- 视频解析模型
- 人格蒸馏（大V风格模拟）

## 技术栈
- React + TypeScript + Tailwind CSS
- shadcn/ui 组件库
- Framer Motion / GSAP 动画
- Three.js / CSS 3D 效果
- 粒子系统
- WebGL 特效

## 执行阶段

### Stage 1 — 深度研究与设计
- 研究 jiejoe.com 的设计手法
- 搜索赛博朋克风网页设计最佳实践
- 搜索KOC/自媒体AI工具竞品分析
- 确定视觉风格系统（色彩、字体、动效规范）
- 输出设计文档

### Stage 2 — 资源生成
- 生成男MCN经纪人形象（二次元乙游风格，多个造型变体）
- 生成女MCN经纪人形象（二次元乙游风格，多个造型变体）
- 生成场景背景图、装饰元素
- 生成帖子封面图样本
- 生成用户头像样本
- 生成其他需要的视觉素材

### Stage 3 — 核心开发（分批进行）
按页面模块分批次开发：
1. 全局框架（路由、主题、音效、粒子背景、鼠标特效）
2. 开场页面 + 时空漩涡过渡 + 经纪人选择
3. MCN引导对话 + 信息收集泡泡
4. 主页仪表盘（任务系统、经纪人、个人主页预览）
5. 推文生成器 + 图像美化化妆间
6. 选题分析 + 爆款搜索 + 可视化
7. 社交板块（好友、电影院、剧本杀、小游戏）
8. 内容研讨地（AI人格讨论群）
9. 悬浮Agent组件

### Stage 4 — 整合与优化
- 页面转场动画
- 响应式适配
- 性能优化
- README编写（API配置说明）
- 部署上线

## 质量目标
- 视觉冲击力强，赛博朋克风格极致
- 交互流畅，动效丰富但不卡顿
- AI功能链路完整标注，方便后续Trae开发
- 所有演示页面有真实内容（生成的图片、模拟数据）
- 在千人中脱颖而出的产品水准
